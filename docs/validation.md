## 実行環境

Python 3.12の既存仮想環境を使用しました。
実行時の主要パッケージは `requirements.txt` と `requirements-dev.txt` の固定版と一致します。
空の仮想環境からのパッケージ再インストールとDockerビルドは今回実施していません。
Node.jsはプロバイダー要求形式の比較に、PlaywrightのChromiumは画面の操作に使いました。
